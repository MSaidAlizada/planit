# planit

Self-hosted personal productivity app for tasks, calendars, habits, and automated scheduling.

## Current status

Project brief and roadmap live in [PLANIT.md](PLANIT.md).

## Stack

- Frontend: React, Vite, TypeScript, Tailwind CSS
- Backend: FastAPI, SQLite, SQLModel, APScheduler
- Deployment: Docker Compose on Raspberry Pi 3B
